Sources

Links are checked against official CVUT pages when possible. Direct service URLs are used for systems that publish stable public entry points.

How Links Are Chosen

The preferred source is an official CVUT, faculty, IST, SUZ, library, or service page that explains the student task behind the link. Direct application URLs are included only when the official public entry point is stable and commonly used by students.

Review Notes

Descriptions on CVUT Crossroad are written as short routing notes, not copied from the source pages. If a service changes ownership, login method, or public URL, the affected entry should be updated or removed.
